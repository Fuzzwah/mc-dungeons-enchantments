# Minecraft Dungeons Enchantment Archive

This folder is ready to publish directly with GitHub Pages.

1. Add all of these files and the `assets/` folder to the root of a GitHub repository.
2. Open **Settings → Pages** in that repository.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose your main branch and the **/(root)** folder, then save.

No build command, package installation, or server is required.
